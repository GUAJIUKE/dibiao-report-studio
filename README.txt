地标检测报告工作台 V3

生产地址：https://guajiuke.github.io/dibiao-report-studio/

当前入口与模块
- index.html：页面入口
- studio.css：桌面/手机界面
- studio.js：项目、机组、现场记录、校验、存储、备份
- model.js：数据结构、兼容迁移、计算及校验
- word.js：保留原模板结构的 Word 生成器
- template.docx：移除批注、示例照片和项目数据后的模板
- jszip.min.js：本地 DOCX 处理依赖

旧版 app.js、core.js、export.js、workflow.js、style.css、readable.css 保留为历史代码；V3入口不再加载。

功能边界
当前支持发电机绝缘与直流电阻检测报告，同一模板可适配多机组、多机型、可配置测试回路和检测范围。
其他种类的报告需要新增模板与字段映射，不能直接套用此模板。
数据、图片、签名只保存在当前浏览器的 IndexedDB。请定期导出备份。导入备份采用合并方式，不删除已有报告。
照片从相册选取或通过手机原生拍照获得；没有第三方水印相机专用接口。可上传其已保存照片。
完整报告需要通过数据、照片、签名、规则与设备检查；草稿可保留缺项。电子签名图片不等于线上审批。
编号仅能检查本浏览器内的重复，多人间仍需统一登记。

本地预览
在本目录运行静态HTTP服务器，浏览器访问本地HTTP地址。不要直接双击index.html（模板通过fetch加载）。
